# Hello World ASCII Art

โปรแกรม Python อย่างง่ายที่แสดงข้อความ **Hello World** พร้อม ASCII Art บนหน้าจอ

## Output

```text
Hello World

       \       /
        \     /
         _.._._
       .' ._  _`.
      /  /   \   \
     |  | (*) (*) |
     \   \   ^   /
      `._ '.___.'
         |     |
         |  |  |
         (  |  )
         /__|__\
```

## Requirements

* Python 3.x

## How to Run

1. Clone repository

```bash
git clone <repository-url>
```

2. เข้าไปยังโฟลเดอร์โปรเจกต์

```bash
cd <project-name>
```

3. รันโปรแกรม

```bash
python main.py
```

## Source Code

```python
print('Hello World')

text = '''
       \\       /
        \\     /
         _.._._
       .' ._  _`.
      /  /   \\   \\
     |  | (*) (*) |
     \\   \\   ^   /
      `._ '.___.'
         |     |
         |  |  |
         (  |  )
         /__|__\\
'''

print(text)
```
